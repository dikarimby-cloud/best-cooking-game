Dapur Kilat (Warung Rush) — a fast-paced top-down cooking game. Run a little Indonesian warung kitchen: take ingredients from the crates, chop them on the boards, cook them on the stoves, build each dish on the plate and serve it at the window before the order's patience runs out. Combos pay more, missed orders end the shift, and every few dishes the kitchen levels up with faster orders and new recipes.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or the arrow keys, or click the floor; press E (or click a station) to take, chop, cook, plate and serve. Q clears the plate, P pauses, M mutes.
